# Central Documentation

This folder contains shared algorithm diagrams, performance analysis and the Unit 7 mini-project report.

## Available

- algorithm-flowcharts/: Lab 1 and Lab 2 flowcharts.
- architecture-diagrams/: Lab 1 production-system and water-jug diagrams.
- performance-analysis.pdf: Existing central performance-analysis document.
- mini-project-report.md and mini-project-report.pdf: Explainable and robust handwritten-digit recognition project.

The mini-project trains a CNN on the Scikit-learn Digits dataset, then evaluates Grad-CAM, FGSM and PCA/SVD on reproducible train/test partitions. Lab-specific logs and figures remain in each lab's outputs folder.
