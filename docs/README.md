# Central Documentation and Architectural Diagrams

This folder stores shared diagrams, performance analysis and the Unit 7 mini-project report.

## Available

- `algorithm-flowcharts/`: Lab 1 flowcharts and the Lab 2 A* search flowchart.
- `architecture-diagrams/`: Lab 1 production-system architecture and water-jug state-space tree.
- `performance-analysis.pdf`: Existing central performance-analysis document.
- `mini-project-report.md` and `mini-project-report.pdf`: Explainable and adversarially robust handwritten-digit recognition mini-project, with experimental results and dashboard figures.

Lab-specific logs, confusion matrices and plots remain in each lab's `outputs/` folder. The Unit 7 mini-project uses the Scikit-learn Digits dataset, a compact residual CNN, Grad-CAM, FGSM, PCA and explicit SVD.
