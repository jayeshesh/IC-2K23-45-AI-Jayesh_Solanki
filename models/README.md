# Trained Models and Checkpoints

The laboratory scripts generate their model checkpoints when run from the repository root.

| Lab | Checkpoint | Generated by |
|---|---|---|
| 6 | models/linear_regression.pt | Lab6/PytorchBasics.py |
| 6 | models/student_score_network.pt | Lab6/NeuralNetwork.py |
| 7 | models/digit_resnet.pt | Lab7/ExplainableAI.py |

Lab 5 uses a Scikit-learn pipeline in memory and does not export a separate estimator checkpoint. Labs 1–4 use symbolic reasoning, preprocessing or search algorithms.
