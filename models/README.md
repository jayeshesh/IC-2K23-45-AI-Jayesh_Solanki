# Trained Models and Checkpoints

This folder stores reproducible model checkpoints generated by the laboratory scripts.

| Lab | File | Framework | Description |
|---|---|---|---|
| 6 | `linear_regression.pt` | PyTorch | Single-layer linear regression state dictionary. |
| 6 | `student_score_network.pt` | PyTorch | Feed-forward score-prediction network plus feature and target scaling statistics. |
| 7 | `digit_resnet.pt` | PyTorch | Compact residual CNN trained on the Scikit-learn Digits dataset. |

Lab 5 uses Scikit-learn's Decision Tree pipeline and does not currently export a separate serialized estimator. Labs 1-4 use search or symbolic reasoning and do not require learned model checkpoints.

The Lab 6 and Lab 7 scripts regenerate their checkpoints when run from the repository root.
